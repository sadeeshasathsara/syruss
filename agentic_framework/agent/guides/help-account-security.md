# Help: signing in and account security

Everything about a person's own sign-in is in the organization's Settings → **Account and security**. Use the page and
button names exactly as written here. You can't see or change anyone's sign-in settings, and you never ask for a
password or a code.

## Sign-in (Settings → Account and security → Sign-in)
- **Your email**: the sign-in, and where codes and invitations arrive.
- **Password**: **Change password** (or **Set a password** for someone who signs in only with Google). It is one
  Syruss sign-in step that comes straight back to this page; they are asked for the current password first if they
  haven't signed in recently.
- **Two-step verification**: a code from an authenticator app (Google Authenticator, Microsoft Authenticator,
  1Password…) as well as the password, so a stolen password isn't enough. **Set up two-step verification** is one
  step: scan the code with the app, enter the 6-digit code it shows. **Add another authenticator app** adds one more;
  **Remove** next to an app removes it. Off, only the password protects the account; it is recommended to turn it on.
- **Google**: sign in with a Google account instead of a password. It shows whether one is linked.
- After any of these steps the page says how it went ("Your password is changed.", "Nothing was changed." if they
  cancelled).
- **Delete your account** (at the bottom): leaves every organization and workspace for good; it can't be undone.

## Keep me signed in
On the sign-in page, ticking **Keep me signed in on this device** keeps that browser signed in for 30 days, asking the
password and any two-step code about once a month. Without it, a session ends after 30 minutes without activity.

## Trusted browsers and emailed codes (Settings → Account and security → Trusted devices)
- Signing in from a browser the account hasn't used before asks for a 6-digit code emailed to the account's address
  ("Confirm it's you"). The code is valid for a short while; a new one can be sent from the same page.
- **Trust this browser for 30 days** (ticked by default) trusts it for 30 days, renewed while it's used; otherwise it is
  trusted for this visit only.
- The Trusted browsers page lists each browser, when it was last used and until when it is trusted. **Remove** one,
  **Sign this one out** for the current browser, or **Remove all other browsers**.
- A code arriving that the person didn't ask for means someone has their password: remove the unknown browser and
  change the password.

## Security activity (Settings → Account and security → Security activity)
New browsers, sign-in codes and removals on the account. If something there isn't them, remove the browser and change
the password.

## Problems you can't solve here
A lost authenticator app with no other way in, a code that never arrives, or a suspected break-in: tell them this needs
Syruss support. Security reports and questions about how the platform is protected also go to support.
